# AGENTS.md - 《人工智慧概論》個人學習講義網站開發指南

## 1. 專案目的
本專案是用於整理《人工智慧概論》課程內容的個人知識庫與講義網站。主要讀者為「自己」，用於課後複習與重點統整。講義會隨著課程進度逐週增加，若某週無課程則允許略過（單元編號可不連續）。

## 2. 視覺風格與設計規範（學術筆記 / Notion 風格）
- **技術棧**：純靜態 HTML5、Tailwind CSS (透過 CDN 載入)、原生 JavaScript，不使用複雜框架，確保能完美在 GitHub Pages 執行。
- **色彩與氛圍**：
  - 背景色：溫潤的淺米白/灰白 (`bg-[#fbfbfa]` 或 `bg-slate-50`)。
  - 字體與排版：標題採用襯線字體 (`font-serif`) 營造紙本講義質感；內文行高寬鬆 (`leading-relaxed`)。
  - 重點提示框：使用柔和的暖色系邊框與背景（例如黃色/琥珀色系 `bg-amber-50 border-amber-300`）來標示核心概念或警示。

## 3. 檔案命名與目錄結構規範
- `index.html`：課程首頁，展示所有單元的總目錄與完成進度。
- `lessons/`：所有單元講義存放的資料夾。
- **命名規則**：`lessons/XX-topic-slug.html`（例如 `01-introduction.html`、`02-search-algorithms.html`）。
  - `XX` 為兩位數單元編號（支援跳號，代表該週無講義）。
  - 後方接英文短標題，單字以連字號 `-` 分隔，全小寫。

## 4. 單元講義頁面的標準結構 (`lessons/*.html`)
每一篇講義頁面必須包含以下固定區塊：
1. **頂部導覽列**：包含「← 返回課程總覽 (`../index.html`)」連結與目前單元編號。
2. **講義標頭 (`<header>`)**：單元標籤、主標題 (`<h1>`)、建立日期與預估閱讀時間。
3. **學習目標區塊**：開頭條列 3-5 個本單元核心目標（使用醒目背景框）。
4. **核心內容 (`<article>`)**：結構化的標題 (`<h2>`, `<h3>`)、條列說明、圖文解說區塊。
5. **底部導覽列**：包含「上一單元」與「下一單元」的跳轉按鈕（若無則隱藏或顯示灰階停用）。

## 5. AI 修改與新增內容時的強制規則
1. **同步更新首頁**：每當在 `lessons/` 新增或修改講義檔案時，**必須同步更新 `index.html` 的目錄清單**，將新單元加入卡片或表格中。
2. **路徑正確性**：位於 `lessons/` 底下的檔案，所有相對連結（返回首頁、引入 CSS/JS）必須正確使用 `../`。
3. **語氣與內容規範**：內容必須使用繁體中文（台灣慣用術語），解釋抽象 AI 概念時，應盡量附帶淺顯易懂的生活化比喻或範例。
4. **保持純淨**：嚴禁要求 npm、Vite 或資料庫建置，維持純靜態檔案，以利直接託管至 GitHub Pages。
